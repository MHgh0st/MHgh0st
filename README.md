### 🚀 Flagship Project: ProcessPulse

> **ProcessPulse** is an enterprise-grade, high-throughput process intelligence and telemetry analytics platform capable of discovering Directly-Follows Graphs (DFG), identifying bottlenecks, computing algebraic duration distributions, and tracing end-to-end case journeys across **1,200,000+ event logs** in sub-second response times.

<div align="center">

| Component | Repository | Highlights & Tech Stack |
|---|---|---|
| **Backend Engine** | [**`ProcessPulse-backend`**](https://github.com/MHgh0st/ProcessPulse-backend) | **FastAPI • Polars (Rust Engine) • ConnectorX • PostgreSQL 15 • ADBC**<br>• Loads 1.2M rows into memory in **0.33s** (44x faster than Pandas/SQLAlchemy)<br>• Vectorized DFG extraction via list-slicing (no Python loops)<br>• Single-pass algebraic variance $E[X^2] - (E[X])^2$ & weighted medians<br>• 8 targeted PostgreSQL B-Tree indexes with SQL predicate pushdown |
| **Interactive Frontend** | [**`ProcessPulse-frontend`**](https://github.com/MHgh0st/ProcessPulse-frontend) | **Next.js 16.1 (Turbopack) • React 19 • Tailwind CSS v4 • HeroUI • @xyflow/react**<br>• Multi-threaded **ELKjs graph auto-layout in Web Workers** (non-blocking 60+ FPS)<br>• Interactive D3 Sankey flow diagram modeling cohort divergence<br>• Real-time ApexCharts latency histograms embedded in hover cards<br>• Obsidian Charcoal design system with classical Merriweather typography |
